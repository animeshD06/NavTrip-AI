Antigravity plan: editorial hero scroll fix

Goal
- Prevent the intro hero words from overlapping the central dot mark while scrolling.
- Match the reference motion: "Born" moves left and "to Travel." moves right as the user scrolls down.

Implementation
- Update `frontend/lib/widgets/home/editorial_scroll_story.dart`.
- Replace the free-positioned hero text stack with a constraint-aware row.
- Reserve three lanes in the hero: left word, center animated dot ring, right phrase.
- Wrap each word in `_HeroWordSlot`, using `FittedBox(scaleDown)` so long text fits its lane on narrow widths.
- Increase scroll translation distance from 36px to 72px in opposite directions:
  - `Born`: negative X offset.
  - `to Travel.`: positive X offset.
- Reduce mobile hero type and dot-ring size slightly to avoid collisions on compact screens.
